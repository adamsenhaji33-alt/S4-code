## Synthèse de ma veille technologique

- Définition en une phrase : La modularité en PHP consiste à organiser le code en plusieurs parties réutilisables grâce aux fonctions et aux fichiers inclus, afin d'éviter la répétition du code.

- Problème résolu pour le projet : Éviter de copier le même code dans plusieurs pages du Blog, réduire les erreurs et faciliter les modifications.

- Mes 3 mots-clés : require_once — Fonctions réutilisables — Principe DRY.
